# Privacy Policy

**PR Description Guard** does not collect, store, or transmit any user data.

## Data Collection

- **No data collection** - The extension does not collect any user data
- **No data storage** - No data is stored locally or remotely
- **No data transmission** - No data is sent to any server
- **No analytics** - No tracking or analytics are used
- **No cookies** - No cookies are set or used

## How It Works

All validation happens locally in your browser. The extension:
- Reads the PR description text from the GitHub page
- Validates it against required sections
- Displays warnings if sections are missing
- All processing is done in your browser, no data leaves your device

## Contact

For questions about privacy, please open an issue on the project repository.
