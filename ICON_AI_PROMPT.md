# AI Icon Generation Prompt

## Optimized Prompt for AI Image Generators

Use this prompt with AI image generation tools (DALL-E, Midjourney, Stable Diffusion, etc.):

```
A minimalist Chrome extension icon, 128x128 pixels, flat design style. A shield shape with rounded top point, warm yellow-amber background (#F0C36D), three horizontal checklist lines inside in dark brown (#735C0F), small white checkmark in top-right corner. Clean, simple, professional, no gradients, no shadows, transparent background, recognizable at small sizes, GitHub-style design aesthetic.
```

---

## Step-by-Step: Generate Icon with AI

### Option 1: DALL-E (OpenAI) - Recommended

1. **Go to:** https://chat.openai.com (if you have ChatGPT Plus) or https://labs.openai.com
2. **Use this prompt:**
   ```
   Create a minimalist Chrome extension icon, 128x128 pixels, flat design. 
   Shield shape with rounded top point, warm yellow-amber background (#F0C36D), 
   three horizontal checklist lines inside in dark brown (#735C0F), 
   small white checkmark in top-right corner. 
   Clean, simple, professional, no gradients, transparent background, 
   GitHub-style design aesthetic.
   ```
3. **Generate** and download the image
4. **Edit** if needed (remove background, adjust colors)
5. **Export** as PNG with transparency

### Option 2: Microsoft Designer (Free)

1. **Go to:** https://designer.microsoft.com
2. **Click:** "Create image from text"
3. **Use this prompt:**
   ```
   Minimalist shield icon, yellow amber background, three horizontal lines, 
   checkmark, flat design, 128x128, transparent background, 
   Chrome extension icon style
   ```
4. **Generate** and download
5. **Edit** colors to match exactly (#F0C36D, #735C0F)

### Option 3: Stable Diffusion (Free - Hugging Face)

1. **Go to:** https://huggingface.co/spaces/stabilityai/stable-diffusion
2. **Use this prompt:**
   ```
   minimalist shield icon, yellow amber background #F0C36D, 
   three horizontal checklist lines dark brown #735C0F, 
   white checkmark, flat design, 128x128 pixels, 
   transparent background, Chrome extension icon, 
   professional, clean, simple
   ```
3. **Negative prompt:**
   ```
   gradients, shadows, 3d, realistic, complex details, text
   ```
4. **Generate** and download

## Alternative: Use Canva with AI

1. **Go to:** https://www.canva.com
2. **Click:** "Create a design" → "Custom size" → 128x128 pixels
3. **Use Magic Media (AI):**
   - Click "Apps" → "Magic Media"
   - Prompt: "Minimalist shield icon with checklist, yellow amber, flat design"
4. **Or manually create:**
   - Add shield shape
   - Add 3 horizontal lines
   - Add checkmark
   - Apply colors

## After Generation: Post-Processing

### 1. Remove Background (if needed)
- **Tool:** https://www.remove.bg (free)
- Upload generated image
- Download with transparent background

### 2. Adjust Colors (if needed)
- **Tool:** Canva, Figma, or GIMP
- Use color picker to set exact colors:
  - Background: #F0C36D
  - Lines: #735C0F
  - Checkmark: #FFFFFF

### 3. Create All Sizes
- **Tool:** Any image editor
- Scale to:
  - 128x128 (original)
  - 48x48 (scale down)
  - 16x16 (scale down)

### 4. Optimize
- Ensure PNG format
- Verify transparency works
- Check clarity at 16x16 size
