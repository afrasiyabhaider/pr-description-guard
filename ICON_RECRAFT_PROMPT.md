## Recraft.ai Specific Optimizations

### For Best Results in Recraft.ai:

1. **Use "Icon" or "Vector" style** - Better for flat designs
2. **Set aspect ratio to 1:1** - Square format
3. **Use negative prompts:**
   - "no gradients"
   - "no shadows"
   - "no 3D"
   - "no realistic"
   - "no complex details"

### Full Prompt with Negative Prompts:

**Positive Prompt:**

```
Flat design Chrome extension icon, 128x128 pixels. Shield shape with rounded top, 
warm yellow-amber background (#F0C36D), three horizontal checklist lines dark brown (#735C0F), 
white checkmark icon top-right, GitHub octocat logo silhouette center, 
document/description icon, minimalist, clean, professional, 
transparent background, GitHub-style design.
```

**Negative Prompt:**
```
gradients, shadows, 3D, realistic, complex details, text, blur, 
photorealistic, depth, perspective, rounded edges on icon elements
```

## Troubleshooting

### If Icon Too Complex:
- Simplify: Remove document icon, keep only GitHub logo
- Use: "Simplified GitHub logo silhouette" instead of full logo

### If Elements Not Clear:
- Increase contrast between elements
- Make GitHub logo larger
- Simplify document icon to just lines

### If Colors Wrong:
- Specify exact hex codes in prompt
- Use Recraft.ai's color adjustment tools
- Regenerate with more specific color instructions

---

**Best Practice: Generate at high resolution (1024x1024) then scale down to ensure clarity at all sizes.**
