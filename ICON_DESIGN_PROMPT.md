# Icon Design Prompt for PR Description Guard

## Project Context

**PR Description Guard** is a Chrome Extension that validates GitHub pull request descriptions to ensure they contain required sections: "What changed", "Why", and "How it was tested". It provides non-intrusive inline warnings without blocking PR creation.

## Icon Design Requirements

### Visual Concept

Create an icon that represents:
- **Guard/Protection** - Protecting PR quality
- **Document/Checklist** - PR descriptions
- **Validation/Check** - Ensuring completeness
- **GitHub Integration** - Works on GitHub PR pages

### Design Style

- **Simple and recognizable** at small sizes (16x16 pixels)
- **Professional** - Matches GitHub's design aesthetic
- **Clean and minimal** - No complex details
- **High contrast** - Visible on light and dark backgrounds

### Color Scheme

**Primary Colors:**
- Background/Warning: `#F0C36D` (warm yellow/amber)
- Text/Borders: `#735C0F` (dark brown)
- Accent: `#fff` (white) for highlights

**Alternative (if needed):**
- Primary: `#0366d6` (GitHub blue)
- Secondary: `#28a745` (GitHub green for checkmark)
- Background: `#fff` or `#24292e` (GitHub dark)

### Icon Concepts

**Option 1: Shield with Document**
- Shield shape (protection/guard)
- Document/paper icon inside
- Checkmark or list icon overlay
- Colors: Yellow/amber background, dark brown details

**Option 2: Document with Checkmark**
- Document/paper icon
- Large checkmark overlay
- Guard/shield border around it
- Colors: Yellow/amber background, dark brown/white details

**Option 3: Checklist Shield**
- Shield shape
- Checklist lines inside (3 lines representing the 3 required sections)
- Checkmark at top
- Colors: Yellow/amber background, dark brown details

**Option 4: PR Badge**
- Circular badge/shield
- "PR" text or document icon
- Guard/shield border
- Checkmark accent
- Colors: Yellow/amber background, dark brown text

### Technical Requirements

- **Sizes needed:** 16x16, 48x48, 128x128 pixels
- **Format:** PNG with transparency
- **Style:** Flat design (no gradients or shadows)
- **Readability:** Must be clear at 16x16 size
- **Transparency:** Use transparent background

### Design Guidelines

1. **Keep it simple** - Details get lost at 16x16
2. **Use bold shapes** - Thin lines don't scale well
3. **High contrast** - Ensure visibility on any background
4. **Centered composition** - Icon should work centered
5. **No text at small sizes** - Text unreadable at 16x16
6. **Consistent style** - All 3 sizes should look the same (just scaled)

### Recommended Design

**Best Option: Shield with Checklist**

- Shield/guard shape as base (rounded rectangle with top point)
- Three horizontal lines inside (representing the 3 required sections)
- Small checkmark icon in top-right corner
- Yellow/amber background (#F0C36D)
- Dark brown details (#735C0F)
- White checkmark for contrast

This design:
- ✅ Clearly represents "guard/protection"
- ✅ Shows "checklist/validation" concept
- ✅ Recognizable at small sizes
- ✅ Matches project's warning/validation theme
- ✅ Professional and GitHub-appropriate

## Free Tools to Create the Icon

### 1. **Canva** (Recommended)
- **URL:** https://www.canva.com
- **Why:** Easy to use, professional templates, free tier available
- **How to use:**
  1. Create custom size: 128x128 pixels
  2. Use shapes (shield, lines, checkmark)
  3. Apply colors (#F0C36D, #735C0F)
  4. Export as PNG with transparency
  5. Scale down to 48x48 and 16x16

### 2. **Figma** (Best for Precision)
- **URL:** https://www.figma.com
- **Why:** Professional design tool, vector-based, free
- **How to use:**
  1. Create new file
  2. Set frame to 128x128
  3. Design icon using shapes and vectors
  4. Export as PNG at 1x, 3x, 8x (for 16, 48, 128)
  5. Perfect for pixel-perfect icons

### 3. **GIMP** (Free & Powerful)
- **URL:** https://www.gimp.org
- **Why:** Free, open-source, full-featured
- **How to use:**
  1. Create new image: 128x128 pixels
  2. Use shape tools and paths
  3. Apply colors and effects
  4. Export as PNG
  5. Scale to other sizes

## Quick Start Guide

### Using Canva (Easiest)

1. Go to https://www.canva.com
2. Click "Create a design" → "Custom size"
3. Set dimensions: 128 x 128 pixels
4. Add shapes:
   - Shield/rounded rectangle with point at top
   - Three horizontal lines inside
   - Small checkmark icon
5. Apply colors:
   - Background: #F0C36D
   - Lines/Details: #735C0F
   - Checkmark: White
6. Export as PNG (transparent background)
7. Use image editor to create 48x48 and 16x16 versions

### Using Figma (Most Professional)

1. Go to https://www.figma.com
2. Create new file
3. Add frame: 128x128
4. Design icon using:
   - Rectangle tool (shield base)
   - Line tool (checklist lines)
   - Vector tool (checkmark)
5. Apply colors from design system
6. Export as PNG at multiple sizes
7. Perfect for all three sizes

### Using GIMP (Most Control)

1. Download and install GIMP
2. File → New: 128x128 pixels
3. Use tools:
   - Path tool (create shield shape)
   - Rectangle tool (checklist lines)
   - Paintbrush (checkmark)
4. Fill with colors
5. Export as PNG
6. Image → Scale Image for other sizes
